# LIMIT identity


Use `LimitLogo` for brand placements. It supplies consistent typography, spacing, sizing and an image with reserved dimensions. The mark is decorative next to the visible LIMIT name, so assistive technology reads the brand only once. Use the large size for entry/account states, the default in the main shell and onboarding, and the small size on public information pages. Keep navigation icons and exercise illustrations distinct from brand identity.

The mark retains its dark square background in both themes, with gently rounded corners in the interface. Preserve the full image and its existing safe margins. Do not apply filters, glows, extra slants or animation to the logo.

The favicon, Apple touch icon and install manifest reference the resized PNGs. `BrandLoading` provides the same static identity and an accessible loading status during application-level loading. The obsolete SVG icon and CSS three-bar brand mark have been removed.
